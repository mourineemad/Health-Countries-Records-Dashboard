# Health Countries' Records | Tableau Dashboard

## Project Overview

This project presents a **Global Health Data Dashboard** developed using Tableau.

It explores health indicators across different countries through geographical visualizations, comparative charts, and statistical analysis.

The dashboard focuses on life expectancy, birth rates, death rates, infant mortality, and HIV population figures, providing different perspectives for exploring and comparing health-related data across countries.

## Dashboard Preview

This section provides a geographical overview of health indicators across countries.

## Key Indicators

The project explores the following health indicators:

| Indicator | Description |
|---|---|
| Birth Rate | Births per 1,000 population |
| Death Rate | Deaths per 1,000 population |
| Infant Mortality Rate | Infant deaths per 1,000 live births |
| Life Expectancy | Life expectancy at birth, measured in years |
| HIV Population | Number of people with HIV across selected countries |

## Project Objectives

- Explore differences in life expectancy across countries.
- Compare birth and death rates between countries.
- Examine the relationship between infant mortality and life expectancy.
- Visualize the geographical distribution of health indicators.
- Explore HIV population figures across selected countries.
- Present global health data through clear and informative visualizations.
